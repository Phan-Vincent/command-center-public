# Contract compatibility reference

See [execution.md](execution.md) for the maintained procedure. Supply one bounded
objective, authorized mode and target, owned file/question scope, exclusions,
constraints, acceptance conditions, required checks, and concise return format.
Send the contract through stdin. Keep secrets and unrelated context out.

Partition only independently verifiable objectives. Use isolated, nonoverlapping
writers. Contracts and directory flags do not establish filesystem confinement;
worker claims do not waive independent inspection and required checks.
